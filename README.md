# Hospital Management System

## Overview
Hospital Management System is a web-based application developed using PHP and MySQL to manage hospital records efficiently.

## Features

- User Login & Registration
- Doctor Management
- Patient Management
- Secure Authentication
- Database Connectivity
- CRUD Operations

## Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript

## Modules

### Login Module
- User Authentication
- Session Management

### Registration Module
- New User Registration

### Doctor Module
- Add Doctor
- View Doctor
- Update Doctor
- Delete Doctor

### Patient Module
- Add Patient
- View Patient
- Update Patient
- Delete Patient

## Database

Tables Used:
- Login
- Registration
- Doctor
- Patient

## Installation

1. Clone the repository
2. Import the database into MySQL
3. Configure database connection
4. Run using XAMPP/WAMP
